LLM post-training

It read everything. It still can't answer you.

A fresh language model is a text-continuing machine. Post-training is how it learns to behave like an assistant.

Before · pretraining

It only knows how
to keep going.

youHow do I boil an egg?
itHow do I fry an egg?
How do I poach an egg?
How do I…

It's finishing your text, not answering it. Nobody ever taught it the difference.

Stage 01 · supervised fine-tuning

Show it good answers.

People write thousands of ideal replies by hand. The model copies the pattern.

Stage 02 · human preferences

Ask which one is better.

Two replies. One person picks the better one. Repeat until a second model can guess the pick every time.

that guessing model is called the reward model

Stage 03 · reinforcement learning

Then let it practice.

It answers, gets scored, tilts a little toward whatever scored well. Millions of times over.

human ratings + practice = RLHF

Two more things happen here

Some answers grade themselves.

Math and code can be checked by a machine. No human needed, so it can practice forever.

And some get a no.

The same training teaches it which requests to turn down, and how to say so.

After

Same knowledge.
New manners.

Pretraining decides what the model knows. Post-training decides how it acts.

SFT
Copying hand-written example answers.
Reward model
A stand-in for human taste.
RLHF
Practice, scored by that stand-in.
RLVR
Practice on answers a machine can check.

Simplified on purpose. In practice these stages overlap, repeat, and vary a lot between labs.
