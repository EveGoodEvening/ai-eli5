# Lessons

- Explainers are standalone HTML files at the repository root. `index.html` discovers root-level HTML pages through the GitHub contents API, excluding itself, and reads their `<title>` elements. New explainers appear automatically after publication; no manual navigation registry is needed.
- Self-contained inline SVG diagrams work without external image or font dependencies. Wide diagrams can use local horizontal scrolling on mobile without overflowing the page.
