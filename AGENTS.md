# Lessons

- Explainers have paired root-level files: `<concept>.en.html` and `<concept>.zh-CN.html` (Simplified Chinese). Keep full content, SVG/accessibility labels, dynamic text, and section IDs aligned across both editions. The unsuffixed `<concept>.html` is a generated compatibility redirect.
- When handling `/eli5-en` or `/eli5-cn`, first ask whether the user wants only the requested language or both English and Simplified Chinese. Use the naming structure `<concept>.en.html`, `<concept>.html`, and `<concept>.zh-CN.html`: always generate `<concept>.html` as the compatibility index/redirect, then generate only the selected localized page or both localized pages according to the answer. Never silently generate the other language when the user chooses one language. When both languages exist, keep their full content, SVG/accessibility labels, dynamic text, and section IDs aligned. Afterward, run `node scripts/prepare-pages.mjs` to synchronize site navigation and generated files.
- `index.html` discovers concepts through the GitHub contents API and reads localized `<title>` elements. Run `node scripts/prepare-pages.mjs` after adding/editing pairs to refresh shared navigation, legacy redirects, and the generated `guides.json` fallback used for local preview. No manual navigation registry is needed. `npm run check` verifies pair completeness and generated files.
- Self-contained inline SVG diagrams work without external image or font dependencies. Wide diagrams can use local horizontal scrolling on mobile without overflowing the page.
- The published site has no npm runtime dependencies; Playwright is development-only. External runtime dependencies are the GitHub contents API for directory discovery and Google Fonts CSS/font resources on pages that include them.
- Puppeteer security probes that intercept GitHub API responses must preserve CORS headers (for example, `Access-Control-Allow-Origin: *`). Otherwise discovery falls back to `guides.json`; assert that the API-derived guide was loaded and the fallback was not requested before claiming coverage of remote discovery.
