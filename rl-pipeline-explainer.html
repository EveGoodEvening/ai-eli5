Training a language model with feedback

Try. Score. Repeat.

A model that only predicts the next word is not yet useful. Here is how it gets taught, one score at a time.

Before any of this

It has read
everything.

And it still has no idea which answer you actually wanted. It only knows which words tend to follow which.

Base model · pretraining

Stage 01

Show it
good answers.

People write out how a reply should look. The model practises copying them until the shape feels natural.

Supervised fine-tuning

Stage 02

Ask which
one is better.

The model writes two replies to the same question. A person points at the better one. Nobody has to explain why.

Preference data

Stage 03

Build a
grader.

A second model studies thousands of those picks until it can guess the human's choice by itself — and hand out a number in milliseconds.

Reward model

Stage 04 · the engine

Now run
the loop.

The model answers. The grader scores it. Whatever it did to earn a high score becomes slightly more likely next time. That last part is the learning.

PPO · GRPO · policy update

Safety rail

Keep it on
a leash.

Chase points too hard and the model forgets how to talk. So a frozen copy of the old version sits alongside it, tugging it back whenever it drifts too far.

Reference model · KL penalty

Failure mode

It will try
to cheat.

The model optimises the grader, not the goal. Padding, flattery and confident nonsense all score well before anyone notices.

Reward hacking

The rig

Four things,
all at once.

Every turn of the loop needs all four loaded and talking to each other. Most of the cost is not the learning — it is waiting for the model to finish writing.
