The problem

Every token looks at every token

5 tokens need 25 comparisons.

Scale it up

More tokens, a much bigger table

Tokens ×10, table ×100.

The hardware

A GPU has two kinds of memory

The huge table will not fit on the desk.

The bottleneck

Moving data takes the time

Fast arithmetic, slow transfers.

The solution

Use small tiles. Finish each one on the desk.

The full table is never stored; only its tiles briefly exist on the desk.

The result

The same math, a different route

ACCURACYExact attention

No attention approximation; floating-point rounding can differ.

SPEEDAbout 3×

Faster training, with larger speedups for attention itself.

MEMORYN² → N

Attention memory no longer grows with the square of the token count.

So models can read much longer texts.

It keeps the same math,
and changes only the route data takes.
